# Dataset NASA MDP (Metrics Data Program)

- **Sumber/URL:** [Kaggle — NASA Software Defect Prediction](https://www.kaggle.com/datasets/aczy156/nasa-software-defect-prediction)
- **Repositori Asal:** PROMISE Software Engineering Repository / NASA MDP
- **Tanggal Unduh:** 24 November 2026
- **Lisensi:** Public Domain / CC0
- **Format File Asli:** `.arff` (Attribute-Relation File Format dari WEKA, bukan `.csv`)
- **Daftar File yang Diunduh:**
  - `CM1.arff` (NASA spacecraft instrument spacecraft module, C)
  - `JM1.arff` (NASA ground system, real-time predictive simulation, C)
  - `KC1.arff` (Storage management system for receiving/processing ground data, C++)
  - `KC3.arff` (NASA satellite data processing, Java)
  - `KC4.arff` (Empty/stub dataset dari uploader - 0 baris data)
  - `MC1.arff` (NASA space & combustion experiment flight software, C & C++)
  - `MC2.arff` (NASA science data collection system, C)
  - `MW1.arff` (Zero gravity combustion experiment, C)
  - `PC1.arff` (Earth orbiting satellite software, C)
  - `PC2.arff` (Dynamic simulator for orbit attitude control, C)
  - `PC3.arff` (Flight software for earth orbiting satellite, C)
  - `PC4.arff` (Flight software for earth orbiting satellite, C)
  - `PC5.arff` (Earth orbiting satellite software, C++)

- **Catatan Reproducibility:**
  File mentah `.arff` tidak diunggah ke repositori GitHub karena telah dimasukkan ke dalam `.gitignore`. Untuk mereproduksi eksperimen, unduh dataset dari Kaggle dan letakkan langsung pada direktori `data/`.
