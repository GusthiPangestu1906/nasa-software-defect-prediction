# Dataset Panduan: NASA Software Defect Prediction

## Sumber Data
Dataset dapat diunduh melalui Kaggle:
- URL: https://www.kaggle.com/datasets/aczy156/nasa-software-defect-prediction

## Instruksi Unduh
1. Unduh berkas dataset dari tautan di atas atau unduh melalui Kaggle API.
2. Tempatkan berkas CSV (misalnya: kc1.csv, jm1.csv, pc1.csv, cm1.csv) ke dalam folder data/.
3. Berkas data mentah sudah diabaikan oleh Git melalui .gitignore.
